
# TP 2 - Activite 2-2 : Echange des objets

## Objectif
Echanger des objets Java entre un client et un serveur avec les sockets TCP.

## Classes
- Operation.java : classe qui implemente Serializable.
- Client.java : cree et envoie un objet Operation.
- Serveur.java : recoit l'objet, effectue le calcul et renvoie le resultat.

## Technologies
- Java
- Sockets TCP
- Serializable
- ObjectInputStream
- ObjectOutputStream

## Execution
1. Lancer Serveur.java.
2. Lancer Client.java.
3. Saisir une operation, par exemple 55 * 25.
4. Saisir quit pour terminer.
